경매한눈 개인정보처리방침

시행일: 2026년 10월 20일

핵심 안내
경매한눈 웹은 카카오 AdFit, Android 앱은 Google AdMob 광고를 표시할 수 있습니다. 비로그인 작업은 기기에, 로그인 후 작업은 계정별 Firestore에 저장하며 광고 요청에 포함하지 않습니다. 사용자가 주소·필지 확인을 요청하면 소재지 또는 PNU가 네이버·VWorld로 전송됩니다.

1. 처리하는 정보

이름, 전화번호와 기기의 GPS 위치를 요구하지 않습니다. 사용자가 직접 추가한 사건번호, 소재지, 메모, 관심 표시와 체크리스트 상태는 현재 브라우저 또는 Android WebView의 로컬 저장소에 저장됩니다. 주소 확인 결과(소재지·좌표)는 반복 조회를 줄이기 위해 최대 7일간 캐시로 사용합니다. 최초 진입 광고의 24시간 노출 제한 시각과 하단 광고의 현재 세션 접힘 상태도 기기에 저장됩니다. 카카오 AdFit 또는 Google AdMob 광고 제공 과정에서 광고 요청·노출·클릭 정보, IP 주소, 브라우저·기기 정보, 쿠키 또는 광고 식별자 등 온라인 식별정보가 자동으로 처리될 수 있습니다. Android 앱은 Google UMP를 통해 지역별 동의 또는 개인정보 선택을 요청할 수 있습니다. 메모에 민감한 개인정보를 기재하지 마세요.

2. 정보의 이용과 보관

비로그인 작업은 브라우저에 저장됩니다. 로그인하면 직접 등록 사건, 관심 목록, 체크리스트, 메모, 공식 확인 기록을 Firebase Authentication의 사용자 식별자에 연결해 서울 리전 Firestore에 저장하고 다른 기기에서 로그인 시 복원합니다. 인증 과정에서 제공자가 허용한 기본 프로필(이름·이메일 등)을 Firebase Authentication이 처리할 수 있습니다. 비밀번호는 경매한눈이 직접 수집하지 않습니다. 비로그인 자료는 사용자가 가져오기를 선택할 때만 계정에 합칩니다. 일반 사용자는 자신의 자료만 접근할 수 있으나 서비스 관리자 권한은 별도 관리됩니다.

계정 작업은 내 계정의 ‘계정 작업 정보 비우기’로 비울 수 있으며 계정 자체 삭제는 별도 지원이 필요합니다. 로그아웃만으로 서버 자료나 미전송 로컬 사본이 삭제되지는 않습니다. 기기 사본은 브라우저 데이터를 삭제하면 제거됩니다. 브라우저 데이터를 지워도 서버의 계정 자료는 유지됩니다. Firebase 인증·서비스 운영 로그에는 별도 보유 정책이 적용됩니다. 광고 관련 정보는 광고 제공·성과 측정·부정 이용 방지를 위해 처리되며 보유기간은 카카오·Google의 정책과 이용자 설정에 따릅니다.

로그인·계정 저장을 위해 Google Firebase 서비스를 사용합니다. 작업 저장 데이터베이스 위치는 서울이며 Firebase Authentication 등 인증 처리 위치와 정책은 Firestore 위치와 별개입니다. Firebase 개인정보 처리 안내를 참고하세요. 카카오·네이버 로그인은 별도 등록·중계 서버 설정이 완료된 경우에만 제공하며 제공자마다 계정은 분리됩니다.

3. 제3자 제공과 위탁

페이지를 열면 네이버 지도 SDK·지도 타일을 자동으로 불러옵니다. 목록의 물건을 선택하거나 주소 확인을 누르면 해당 소재지가 네이버 Geocoding으로 전송됩니다. 지적도를 선택하면 jsDelivr에서 지도 엔진을 불러오고 VWorld 배경지도·연속지적도에 현재 지도 영역을 요청합니다. 필지 찾기 시 소재지는 VWorld로, 필지 경계 조회 시 PNU는 VWorld로 전송됩니다. 기기의 GPS 위치는 요청하지 않습니다. 웹 광고 제공을 위해 카카오 AdFit과 통신하며 카카오 개인정보 보호 안내가 적용됩니다. Android 앱에서는 Google AdMob·UMP와 통신하며 Google 개인정보처리방침이 적용됩니다. 사건번호·메모·관심 목록·체크리스트·검색어·물건 좌표는 광고 요청 항목으로 직접 전송하지 않습니다. 외부 지도·광고 요청 과정에서 IP 주소·접속 도메인 등 통신 정보가 해당 제공자에게 전달될 수 있습니다. 토지이음 원문 링크에는 선택한 PNU가 포함됩니다. 각 제공자의 이용조건과 개인정보처리방침이 적용됩니다.
