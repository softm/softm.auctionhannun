공통 Cloudflare 계정 및 경매 전용 보관소

기본 로그인·회원가입은 Cloudflare 공통 계정 Worker를 이용합니다. SNS 식별자와 제공자가 허용한 이름·프로필 사진은 공통 계정 D1에서 관리합니다. 별도 경매 전용 Worker·D1의 동기화가 정상 연결된 경우에만 등록 사건·관심물건·체크리스트·메모를 계정별 암호문으로 저장합니다. 전용 서버가 연결되지 않은 경우에는 화면에 안내하고 현재 기기의 로컬 사본만 유지합니다. 기존 Firebase 보관소는 명시적인 이전 계정 모드에서만 접근하며 자동 이관·병합·삭제하지 않습니다. 공통 계정 개인정보 안내

핵심 안내
경매한눈 웹은 카카오 AdFit, Android 앱은 Google AdMob 광고를 표시할 수 있습니다. 비로그인 작업은 기기에, Cloudflare 로그인 후 작업은 전용 경매 서버 동기화가 연결되면 계정별 D1에 암호화 저장하며 광고 요청에 포함하지 않습니다. 사용자가 주소·필지 확인을 요청하면 소재지 또는 PNU가 네이버·VWorld로 전송됩니다.

1. 처리하는 정보

이름, 전화번호와 기기의 GPS 위치를 요구하지 않습니다. 사용자가 직접 추가한 사건번호, 소재지, 메모, 관심 표시와 체크리스트 상태는 현재 브라우저 또는 Android WebView의 로컬 저장소에 저장됩니다. 주소 확인 결과(소재지·좌표)는 반복 조회를 줄이기 위해 최대 7일간 캐시로 사용합니다. 최초 진입 광고의 24시간 노출 제한 시각과 하단 광고의 현재 세션 접힘 상태도 기기에 저장됩니다. 카카오 AdFit 또는 Google AdMob 광고 제공 과정에서 광고 요청·노출·클릭 정보, IP 주소, 브라우저·기기 정보, 쿠키 또는 광고 식별자 등 온라인 식별정보가 자동으로 처리될 수 있습니다. Android 앱은 Google UMP를 통해 지역별 동의 또는 개인정보 선택을 요청할 수 있습니다. 메모에 민감한 개인정보를 기재하지 마세요.

2. 정보의 이용과 보관

비로그인 작업은 브라우저에 저장됩니다. Cloudflare SNS 로그인은 공통 UID·기본 프로필·일시적 앱 세션을 처리합니다. 전용 경매 Worker·D1의 연결이 정상인 경우 등록 사건, 관심 목록, 체크리스트, 메모, 공식 확인 기록은 해당 UID로 구분되어 계정별로 저장되고 다른 기기에서 복원됩니다. 데이터는 경매 전용 Worker에서 AES-GCM으로 암호화해 D1에 보관하며, 서버는 저장과 조회 시 데이터를 처리합니다. 전용 서버 장애 또는 미배포 상태에서 로그인해도 로컬 기록은 삭제하지 않으며 서버 저장이 완료되었다고 표시하지 않습니다. 비로그인 자료는 명시적으로 가져오기한 경우에만 합쳐집니다. 서비스 비밀번호를 직접 수집하지 않습니다.

작업 기록은 내 작업공간에서 백업하고 비울 수 있습니다. 계정 탈퇴는 기존 보관소와 신규 보관소의 전체 삭제 기능이 검증될 때까지 제한됩니다. 로그아웃만으로 서버 자료나 미전송 로컬 사본이 삭제되지는 않습니다. 기기 사본은 브라우저 데이터 삭제 시 제거될 수 있습니다. 계정 제공자 및 서비스 운영 로그에는 각자의 별도 보유 정책이 적용됩니다. 광고 관련 정보의 보유는 광고 제공자의 정책과 설정에 따릅니다.

기본 로그인·회원가입은 Cloudflare Workers·D1을 이용하며, Google·카카오·네이버 제공자 중 실제로 서버에 설정되고 승인된 로그인 수단을 이용할 수 있습니다. 동일한 사용자가 다른 SNS를 명시적으로 연결한 경우에만 공통 계정으로 묶이며 이메일 일치만으로 자동 병합하지 않습니다. 이전 Firebase 계정·Firestore 자료는 기존 계정 모드에서만 별도로 접근하고 자동 삭제하지 않습니다. 기존 Firebase 개인정보 안내를 참고하세요.

3. 제3자 제공과 위탁

페이지를 열면 네이버 지도 SDK·지도 타일을 자동으로 불러옵니다. 목록의 물건을 선택하거나 주소 확인을 누르면 해당 소재지가 네이버 Geocoding으로 전송됩니다. 지적도를 선택하면 jsDelivr에서 지도 엔진을 불러오고 VWorld 배경지도·연속지적도에 현재 지도 영역을 요청합니다. 필지 찾기 시 소재지는 VWorld로, 필지 경계 조회 시 PNU는 VWorld로 전송됩니다. 기기의 GPS 위치는 요청하지 않습니다. 웹 광고 제공을 위해 카카오 AdFit과 통신하며 카카오 개인정보 보호 안내가 적용됩니다. Android 앱에서는 Google AdMob·UMP와 통신하며 Google 개인정보처리방침이 적용됩니다. 사건번호·메모·관심 목록·체크리스트·검색어·물건 좌표는 광고 요청 항목으로 직접 전송하지 않습니다. 외부 지도·광고 요청 과정에서 IP 주소·접속 도메인 등 통신 정보가 해당 제공자에게 전달될 수 있습니다. 토지이음 원문 링크에는 선택한 PNU가 포함됩니다. 각 제공자의 이용조건과 개인정보처리방침이 적용됩니다.
