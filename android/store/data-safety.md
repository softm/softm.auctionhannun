# Google Play 데이터 보안 답변 기준

- 데이터 수집·공유 답변: 지도 연동 버전 기준 재검토 필요. 기존 버전의 '없음' 답변을 그대로 제출하지 않음
- 회원가입: 없음
- 광고: 없음
- 분석 SDK: 없음
- 위치 권한: 사용하지 않음
- 앱이 저장하는 내용: 사건·메모·관심 표시·체크리스트는 WebView 로컬 저장. 성공한 주소 좌표는 최대 7일간 캐시로 사용
- 네이버 지도: 지도 사용 시 지도 SDK/타일 요청, 주소 확인 버튼 사용 시 해당 소재지 전송. 사건번호·메모·체크리스트는 보내지 않음
- VWorld: 필지 찾기 시 소재지, 경계 조회 시 선택한 PNU 전송
- 토지이음: 원문 열기 시 선택한 PNU를 포함한 공식 웹페이지 연결
- 네트워크 제공자는 요청 과정에서 IP·브라우저 정보·서비스 출처 등을 처리할 수 있음. 각 제공자의 현행 정책과 SDK 동작을 확인해 Play 분류·일시 처리·공유 예외 해당 여부를 검토할 것
- 전송 중 암호화: 앱의 네트워크 연결은 HTTPS만 허용
- 데이터 삭제: Android 설정에서 앱 데이터 삭제 또는 앱 제거 시 로컬 저장 내용 삭제

공식 사이트를 외부 브라우저에서 열면 해당 사이트의 별도 데이터 처리방침이 적용됩니다.

온비드 공공데이터 API 키는 수집 작업의 서버/CI 환경변수로만 사용하며 웹/앱에 포함하지 않습니다. 이 문서는 검토 메모이며 Play 데이터 보안 양식 제출 완료를 의미하지 않습니다.
