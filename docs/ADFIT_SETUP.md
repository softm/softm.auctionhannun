# 경매한눈 AdFit 배너 운영

## 배치

- 목록 상태 안내와 첫 물건 사이에 `320 × 100` 배너 한 개를 표시합니다.
- 같은 광고 단위를 한 화면에 중복 사용하지 않습니다.
- Android 네이티브 광고가 `AdMobNative/1` 사용자 에이전트를 사용하는 경우 웹 광고는 자동으로 숨깁니다.

## 동작

- 광고가 화면 200px 이내로 진입할 때 SDK를 요청합니다.
- 광고 단위가 없거나 잘못되었거나, SDK 오류·광고 없음·30초 무응답이면 빈 지면을 제거합니다.
- `adfit-config.js`의 `enabled`는 경매한눈 전용 AdFit 광고 단위가 발급되어 `true`입니다.
