# 지도 동작 점검 (2026-10-21)

- 페이지 시작 시 NAVER 지도를 자동 표시한다. 실패 시 오류와 재연결 버튼을 표시한다.
- 목록 카드/제목은 지도 이동, 검토하기는 상세 검토 화면을 연다. 관심 버튼은 지도 이동을 일으키지 않는다.
- 선택한 물건만 기존 좌표 또는 NAVER 주소 변환으로 위치를 찾는다. 실패하거나 후보가 불명확하면 임의 위치를 표시하지 않는다. 연속 선택 시 마지막 선택만 이동한다.
- 지적도 버튼은 토지한눈의 OpenLayers 10.6.1 + VWorld XYZ 배경지도 + TileWMS 연속지적도 구성을 사용한다. 원본 프로젝트와 키는 변경하지 않는다.
- 운영 주소는 기존 경매한눈 키, `http://localhost:3000`은 별도 로컬개발 키를 선택한다. 실제 접속 origin만 전송하며 다른 사이트의 도메인으로 위장하지 않는다. 등록하지 않은 127.0.0.1, 다른 포트/스킴은 요청 전에 안내한다.
- NAVER/VWorld 전환 시 중심과 확대 수준을 유지한다. VWorld 지적도는 확대 수준 16 이상에서 표시한다.
- 지적 경계는 참고 자료이며 경매 대상 범위나 법적 경계 확정을 뜻하지 않는다. 사용자 GPS는 요청하지 않는다.

## 실제 확인 결과

- localhost:3000에서 지도 자동 표시, 세종특별자치시 연서면 와촌리 1084-4 목록 선택 후 위치 이동, VWorld 배경지도와 선택 마커 표시 확인.
- 10월 20일 운영 키를 localhost에서 사용하면 WMS가 XML `INCORRECT_KEY`를 반환했다. 10월 21일 로그인 후 운영 키의 WMS 사용 설정과 등록 도메인이 정상임을 확인했다.
- 이미 발급된 `경매한눈 로컬개발` 키(등록 URL `http://localhost:3000`, 발급일 2026-10-21, 만료일 2027-04-21)를 확인하여 적용했다. 중복 발급하지 않았으며 기존 운영 키와 토지한눈 키는 변경하지 않았다.
- 새 로컬 키로 WMS HTTP 200 `image/png` 응답과 실제 브라우저의 주황색 필지 경계·지번 표시를 확인했다. 운영 주소의 새 지도 코드 검증은 배포 후 별도로 필요하다.
- 로컬 변경과 빌드이며 원격 푸시/Pages 배포는 수행하지 않았다.
