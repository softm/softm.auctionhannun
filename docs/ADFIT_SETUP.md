# 경매한눈 AdFit 광고 운영

점검일: 2026-10-22 (KST). 운영 주소: <https://auctionhannun.designboard.net/>.

## 적용 계획

| 지면 | 크기 | 노출 조건 | 사용자 동작 |
| --- | --- | --- | --- |
| 하단 접힘 배너 | 넓은 화면 728×90, 좁은 화면 320×100 | 승인 운영 도메인, 실제 표시 가능 너비 | 광고 영역 밖의 접기·펼치기 버튼. 탭 세션에서 접힘 선택 복원 |
| 목록 인피드 | 지면이 충분하면 728×90, 그 외 320×100 | 검색 결과 5개 이상, 5번째 물건 다음, 화면에 들어올 때 | 광고 DOM은 고정하고 앞뒤 물건 카드만 갱신. 목록 번호와 지도 마커 수에 포함하지 않음 |
| 첫 진입 팝업 | 300×250 예약 설정 | `enabled:false`, `policyApproved:false`로 실제 요청 비활성 | 별도 배치 적합성 검토 후에만 활성화 검토 |

한 화면에는 하단과 목록의 두 배너를 사용합니다. 목록 배너를 여러 번 반복 복제하지 않습니다. PC에서도 목록 영역이 728px보다 좁으면 320px 단위를 사용하며 광고를 CSS로 축소하거나 잘라 표시하지 않습니다.

돌봄한눈의 `care-list-ads.js`를 참고해 실제 펼침 시 요청, 세션 선택 보존, 읽기·입력 시 임시 숨김, 광고 미수신 시 공간 반환을 적용했습니다. 광고단위는 경매한눈에 발급된 전용 값입니다.

## 동작 원칙

- 접힌 채로 진입하면 하단 광고를 요청하지 않습니다. 처음 펼칠 때 요청합니다.
- 이미 로드된 광고는 같은 화면 너비에서 접기·펼치기, 검색·정렬만으로 다시 요청하지 않습니다. 목록 광고의 iframe은 DOM에서 떼거나 다른 위치에 다시 삽입하지 않습니다.
- 화면이 좁아져 기존 하단 광고 규격이 들어가지 않으면 자동으로 접습니다. 사용자가 다시 펼칠 때만 기존 단위를 정리하고 현재 지면에 맞는 단위를 요청합니다. 화면 크기 변경 자체로 새 노출을 요청하지 않습니다.
- 상세 검토, 사건 등록·계정 대화상자, 검색 입력 중에는 광고를 숨깁니다. 작업 종료 후 사용자의 접힘 선택을 복원합니다.
- 브라우저 창 또는 실제 보이는 화면의 높이가 600px 미만이면 광고를 임시 숨겨 가로 화면·키보드 표시 때 지도의 실영역을 확보합니다. 높이가 회복되면 기존 광고와 접힘 선택을 재사용합니다.
- 광고가 있는 동안 하단 공간과 지도 표시 높이를 맞추고, 모바일 하단 메뉴·화면 안전 여백을 고려합니다.
- 요청 중에는 광고 크기만큼 자리를 잠시 확보합니다. SDK가 광고 없음·실패를 알리거나 SDK 파일 로딩이 실패하면 해당 지면과 여백을 숨깁니다. 30초 안에 광고 iframe이 생성되지 않은 경우에도 지면을 정리합니다. iframe 존재만으로 실제 광고 소재 송출 성공을 보장하지는 않습니다.
- 광고를 처음 요청할 때 SDK를 한 번 로드하고, 새 지면은 `adfit.render(element)`로 개별 렌더링합니다. 기존 지면을 함께 새로 고칠 수 있는 전역 `adfit()` 재호출은 하지 않습니다.
- 각 지면에 별도의 성공·실패 콜백을 사용합니다. 제거한 광고는 `adfit.destroy(unit)`으로 SDK에서도 정리합니다. 실패한 지면은 같은 페이지에서 자동 반복 요청하지 않습니다.
- 승인 도메인 `auctionhannun.designboard.net`의 HTTPS 페이지에서만 광고를 요청합니다. 개발·미리보기 호스트에서는 실제 광고를 호출하지 않습니다.
- 네이티브 AdMob이 활성화된 앱이 `AdMobNative/1`을 전달하면 웹 AdFit을 숨겨 중복을 방지합니다. 현재 Android 릴리스의 AdMob은 운영 ID 설정 전 비활성입니다.

## 검증과 운영

`npm run check`와 `npm run build`로 수집자료·소스·기능 검증 후 배포합니다. 광고 라이프사이클 테스트는 가짜 SDK를 사용해 실제 광고 노출을 만들지 않고 초기 접힘, 반복 펼침, 실패 정리, 저장소 제한, 지면 너비, 비활성 호스트와 팝업 차단을 확인합니다.

운영 화면에서는 실제 광고 응답 여부, 광고 바깥 접힘 버튼, 모바일·PC 너비, 검색·상세 열기 시 가림 여부를 확인합니다. 광고를 클릭하는 검증은 하지 않습니다. 광고 재고·차단기·네트워크 상태에 따라 광고가 미수신될 수 있습니다.
