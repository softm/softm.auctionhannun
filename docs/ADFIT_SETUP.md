# 경매한눈 AdFit 광고 운영

## 배치 계획

- 최초 진입: 같은 페이지 안의 `300 × 250` 안내형 광고를 최대 24시간에 한 번 노출합니다. 광고가 실제 로드된 뒤에만 열고 닫기·바깥 영역·Esc로 즉시 닫을 수 있습니다.
- 목록 인피드: 다섯 번째 물건 다음에 모바일 `320 × 100`, PC `728 × 90` 중 화면 크기에 맞는 단위 하나를 삽입합니다.
- 하단 접힘: 모바일 `320 × 100`, PC `728 × 90` 단위를 화면 하단에 표시하며 사용자가 접거나 다시 펼칠 수 있습니다. 접힘 상태는 현재 탭 세션에만 저장합니다.
- 각 지면과 화면 크기는 서로 다른 광고 단위를 사용합니다. 동일 `DAN-` 코드를 한 화면에 중복 호출하지 않습니다.
- Android 네이티브 광고가 `AdMobNative/1` 사용자 에이전트를 사용하는 경우 웹 광고는 모두 자동으로 숨깁니다.

## 동작과 보호 장치

- 인피드 광고는 화면 240px 이내에 들어올 때만 SDK를 요청합니다. 최초 진입·하단 광고는 페이지 준비 후 한 번만 요청합니다.
- 필터·정렬로 목록을 다시 그릴 때 이미 로드한 인피드 DOM을 이동해 불필요한 재호출을 막습니다.
- 광고 단위가 없거나 잘못되었거나, 너비가 부족하거나, SDK 오류·광고 없음·30초 무응답이면 빈 지면을 제거합니다.
- 새 창이나 별도 팝업 페이지를 만들지 않습니다. 최초 진입 지면은 현재 문서 안의 접근 가능한 대화상자입니다.
- 광고 클릭을 유도하는 문구·애니메이션을 사용하지 않고 광고 라벨과 콘텐츠를 명확히 구분합니다.
