PRIVACY POLICY

경매한눈 개인정보처리방침

시행일: 2026년 10월 19일

핵심 안내
회원가입·광고·분석 도구와 기기 GPS를 사용하지 않습니다. 사건·관심 표시·체크리스트·메모는 기기에 저장합니다. 사용자가 주소·필지 확인을 요청하면 소재지 또는 PNU가 네이버·VWorld로 전송됩니다.

1. 처리하는 정보

이름, 전화번호, 이메일, 광고 식별자와 기기의 GPS 위치를 요구하지 않습니다. 사용자가 직접 추가한 사건번호, 소재지, 메모, 관심 표시와 체크리스트 상태는 현재 브라우저 또는 Android WebView의 로컬 저장소에 저장됩니다. 주소 확인 결과(소재지·좌표)는 반복 조회를 줄이기 위해 최대 7일간 캐시로 사용합니다. 메모에 민감한 개인정보를 기재하지 마세요.

2. 정보의 이용과 보관

로컬 저장 정보는 사용자의 경매 검토 목록과 진행 상태를 기기에서 다시 보여주는 데만 사용됩니다. 운영자는 해당 정보에 접근하거나 별도 서버에 보관하지 않습니다. 앱 데이터 또는 브라우저 저장 데이터를 삭제하면 함께 삭제됩니다.

3. 제3자 제공과 위탁

지도 켜기를 요청하면 네이버 지도 SDK·지도 타일을 불러옵니다. 주소 확인 시 소재지는 네이버 Geocoding으로, 필지 찾기 시 소재지는 VWorld로, 필지 경계 조회 시 PNU는 VWorld로 전송됩니다. 사건번호·메모·관심 목록·체크리스트는 전송하지 않습니다. 외부 지도 요청 과정에서 IP 주소·접속 도메인 등 통신 정보가 해당 제공자에게 전달될 수 있습니다. 토지이음 원문 링크에는 선택한 PNU가 포함됩니다. 각 제공자의 이용조건과 개인정보처리방침이 적용됩니다.

4. 정부기관 비제휴 및 공식 출처

경매한눈은 대한민국 정부나 법원에서 운영하거나 보증하는 앱이 아닌 독립적인 검토 도구입니다. 화면의 자료는 참고용이며 법적 효력이 있는 최신 정보와 서류는 아래 공식 원문에서 다시 확인해야 합니다.
